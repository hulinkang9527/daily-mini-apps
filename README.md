# Daily Mini Apps · 每日一个有趣小应用

每天自动生成一个**自包含的趣味小应用**（单文件 HTML，开箱即玩），随机主题：小游戏 / 实用小工具 / 创意玩物。

在线体验：<https://hulinkang9527.github.io/daily-mini-apps/>

## 规则

- 每天 09:00 自动生成并上传，文件按日期命名（如 `2026-10-13.html`）
- 单文件自包含：内联 CSS + JS，浏览器直接打开就能玩
- 手机 / 电脑都能玩
